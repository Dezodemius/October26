# Просмотр и скачивание

«Смотреть» использует ограниченный временный буфер: фильм не докачивается
целиком в фоне, следующая серия заранее не загружается. Для сохранения нажмите
«Скачать», выберите конкретную раздачу и проверьте её название, размер и состав.
После подтверждения скачивается вся раздача; сезонный пак — со всеми его файлами.
В разделе «Загрузки» раздачи показаны отдельно, под исходными названиями.
Полностью скачанный доступный файл запускается с диска без поиска раздачи и пиров.
