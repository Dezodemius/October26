# Октябрь 26 на компьютере с Windows

Смотрите фильмы на этом компьютере и с телефона, планшета или телевизора в вашей домашней сети. Аккаунта и регистрации нет.

## 1. Запуск

1. Распакуйте архив в любую папку, например `Документы\Октябрь 26`.
2. Дважды щёлкните **`october26.exe`**.
   - Windows может написать «защитила ваш компьютер»: нажмите **Подробнее → Выполнить в любом случае**. Программа не подписана, поэтому Windows так реагирует.
   - Брандмауэр спросит доступ к сети: разрешите для **частных сетей**. Без этого другие устройства не увидят Октябрь 26.
3. Откройте в браузере http://localhost:8095.

Окно с журналом должно оставаться открытым: закроете его — Октябрь 26 остановится.

## 2. Смотреть с других устройств

В окне программы и в **Настройки → Открыть с других устройств** написаны адреса, например `http://192.168.1.20:8095`. Откройте его на телефоне, планшете или телевизоре, подключённом к той же сети.

Пробрасывать порты в роутере не нужно: это нужно только для доступа из интернета. Для домашней сети достаточно разрешения в брандмауэре Windows.

### Постоянно включённый ПК как домашний сервер

1. Подключите ПК к домашней сети; для стабильного видео предпочтительнее Ethernet.
2. В Windows выберите для домашнего подключения профиль **Частная сеть**.
3. На роутере закрепите за ПК адрес в настройках DHCP, например `192.168.1.20`.
4. Запустите `october26.exe`. В `kinodom.json` параметр `listen` должен быть
   `:8095` (значение по умолчанию), а не `127.0.0.1:8095`.
5. Разрешите приложению входящие подключения в брандмауэре Windows для частных
   сетей. Если требуется отдельное правило: **Дополнительные параметры →
   Правила для входящих подключений → Создать правило → Для порта → TCP → 8095 →
   Разрешить подключение → Частный**. В области действия ограничьте удалённые
   адреса локальной подсетью.
6. Отключите автоматический сон ПК, когда требуется доступ с других устройств.
7. Для автозапуска после входа в Windows добавьте ярлык `october26.exe` в папку,
   открываемую командой `shell:startup` через Win+R. В свойствах ярлыка укажите
   рабочую папку рядом с EXE: там находятся настройки и база. До входа в учётную
   запись такой автозапуск не работает; отдельная установка службы пока не предусмотрена.
8. На другом устройстве откройте в браузере `http://192.168.1.20:8095`, заменив
   адрес на адрес ПК из окна программы.

Порт **8095/TCP** нужен интерфейсу и воспроизведению по HTTP. Порт **50777/TCP и
UDP** относится к BitTorrent; для открытия интерфейса другими устройствами его
разрешать или пробрасывать не требуется. Проброс 8095 с интернета не нужен.

Если телефон не видит ПК, проверьте, что он находится в той же домашней сети,
а не в гостевой сети с изоляцией клиентов. VPN также может мешать доступу к LAN.

Установленное Android-приложение использует свой хаб на устройстве: поиск и видео
идут через него. ПК может быть центральным хабом общего профиля: прогресс, списки и
историю будут видеть все ваши устройства. Видео при этом по-прежнему идёт с хаба,
запущенного на самом устройстве. Подробности — в инструкции для ТВ, раздел «Общий профиль на хабе».

## 3. Где лежат фильмы

По умолчанию фильмы идут в папку `media` рядом с `october26.exe`. Чтобы хранить их на другом диске или на сетевом накопителе:

1. **Настройки → Хранилище фильмов**.
2. Выберите диск из списка или нажмите **Выбрать другую папку…**.
3. Для сетевого диска нажмите **Найти в сети** в блоке «Сетевые диски»: Октябрь 26 сам найдёт в домашней сети роутер с USB-диском, NAS или другой компьютер и покажет их общие папки. Если гостем не пускают, введите логин и пароль. Подключать сетевой диск в Windows для этого не нужно. Путь можно вписать и вручную: `\\nas\video\Kinodom` или `smb://nas/video/Kinodom`.
4. Нажмите **Сюда** или **Хранить фильмы здесь**. Октябрь 26 перезапустится.

Уже скачанное остаётся в прежней папке. То, что хранится постоянно (скачано целиком или кнопкой «Скачать»), Октябрь 26 докачает в новую папку. Остальное скачается по мере просмотра.

Сетевой диск медленнее внутреннего. Для плавного просмотра нужна проводная сеть и накопитель с SMB.

Если при запуске выбранный диск недоступен (NAS выключен, флешку вынули), Октябрь 26 всё равно откроется и временно будет хранить фильмы в папке `media`. Когда диск появится, Октябрь 26 сам перезапустится и вернётся к нему.

## 4. Звук и браузер

Для воспроизведения в браузере нужны FFmpeg и FFprobe. Установите их одной командой в PowerShell:

```
winget install Gyan.FFmpeg
```

Затем перезапустите Октябрь 26.

## 5. Где что хранится

Рядом с `october26.exe`:

- `kinodom.json` — настройки;
- `data` — база: прогресс просмотра, списки «Позже» и «Избранное», история, постеры;
- `media` — фильмы, если не выбрана другая папка.

## 6. Обновление и удаление

**Обновление.** Скачайте архив `october26-desktop-ВЕРСИЯ.zip` со страницы релизов, закройте Октябрь 26 и замените `october26.exe`. Настройки и база сохранятся.

Если в старой версии программа называлась `kinodom.exe`, закройте её и положите `october26.exe` в ту же папку. Старый EXE можно удалить. Файл `kinodom.json`, папки `data` и `media` сохраните.

**Удаление.** Закройте Октябрь 26 и удалите папку. Фильмы на выбранном диске останутся: папку `Kinodom` удалите вручную, если она не нужна.
